# Food Delivery Analytics Dashboard

## Overview
An interactive Power BI dashboard built to analyze food delivery business performance. The dashboard provides insights into revenue, customers, restaurants, and delivery operations using Power BI.

## Features
- Executive Overview
- Customer Analytics
- Restaurant Performance
- Delivery & Operations
- Advanced Insights

## Tech Stack
- Power BI
- Power Query
- Basic DAX
- Excel

## Key Metrics
- Total Revenue
- Total Orders
- Average Order Value (AOV)
- Average Delivery Time
